تطبيق أرشيف إدارة الموازنة - Android APK

هذا مشروع Android مجاني يفتح موقع الأرشيف داخل تطبيق أندرويد، مع دعم JavaScript ورفع الملفات من الهاتف.
لا توجد مدة تجريبية أو اشتراك في هذا المشروع. لا يتطلب نشر التطبيق على Google Play؛ يمكن تثبيت ملف APK يدويًا.

أسهل طريقة للحصول على APK دون دفع:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub جديد أو مستودع تملكه.
2) افتح تبويب Actions في المستودع.
3) اختر Build Android APK ثم Run workflow.
4) بعد انتهاء البناء، افتح نتيجة التشغيل (workflow run) ونزّل Artifact باسم NCW-Archive-APK.
5) فك ضغط الملف على الهاتف وثبّت app-debug.apk. قد تحتاج للسماح بالتثبيت من هذا المصدر في إعدادات أندرويد.

مهم:
- التطبيق يحتاج إنترنت لفتح الموقع المنشور.
- هذا غلاف Android للموقع، وليس إعادة بناء كاملة للنظام.
- الكود الحالي للموقع يحفظ بيانات الأرشيف محليًا في المتصفح ويستخدم روابط مؤقتة للملفات؛ لذلك لا تعتبره قاعدة بيانات مشتركة أو أرشيفًا مضمونًا للملفات بعد إعادة التشغيل. يلزم تعديل الموقع/الخادم قبل استخدامه لحفظ مستندات رسمية مهمة أو مشاركتها بين عدة مستخدمين.
- كلمة مرور الأدمن الموجودة في كود الموقع ليست حماية آمنة لأنها ظاهرة داخل JavaScript. لا تستخدمه لمستندات سرية قبل إضافة مصادقة وخادم آمن.
